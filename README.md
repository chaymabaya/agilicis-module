
🍅 Tomato Plant Disease Detection
📌 Project Overview

This project is an AI-based system for detecting tomato plant diseases from leaf images.
The system uses a Convolutional Neural Network (CNN) model to analyze uploaded images and predict the type of disease.

Users can upload a tomato leaf image through a web interface and receive an instant prediction.

🧠 System Architecture
The system is composed of three main parts:

Frontend: React application hosted on Railway

Backend: FastAPI API hosted on Railway

AI Model: CNN model for image classification

Workflow:

User uploads an image from the web interface.

The image is sent to the FastAPI backend.

The backend processes the image using the CNN model.

The model predicts the disease.

The result is returned to the frontend and displayed to the user.
